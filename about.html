Course context

JSC370 is a project-based data science course at UofT; this final project is the capstone deliverable. It builds on a midterm submission that scoped the same dataset with linear-model baselines on raw count outcomes; the final project adds a per-capita rate target, tree-based models, lag features, and a COVID-period inferential specification with an explicit year-by-post-2020 interaction.

Data sources

Five tables, all from Statistics Canada’s bulk CSV API (no API key required):

  • 17-10-0149-01 — Components of population change by CMA, 2021 boundaries — provides the two outcomes (net_interprovincial, net_intraprovincial) plus intl_inmigration and natural_increase_rate.
  • 17-10-0148-01 — Population estimates, July 1, by CMA — total population and age-share breakdown (share_25_44, share_65plus).
  • 34-10-0133-01 — CMHC average rents for areas with population ≥ 10,000 — avg_rent and derived rent_deviation.
  • 14-10-0020-01 — Unemployment, participation, and employment rate by educational attainment — provincial unemployment_rate and participation_rate.
  • 27-10-0273-02 — Expenditures on research and development by performing sector — provincial rd_provincial.

No API key or authentication is required for any of these tables; the pipeline downloads the bulk-CSV ZIP for each table and caches it locally under data/raw/ (gitignored). Re-running the pipeline reuses the cache.

Reproducibility

The entire analysis is reproducible from a clean clone by rendering two notebooks:

# From the project directory
cd JSC370_2026/project/canada_migration

# 1. Rebuild outputs/tables/* and outputs/figures/*
quarto render migration_analysis.qmd

# 2. Rebuild the written report as HTML
quarto render final.qmd

# 3. Build this website (outputs to site/_site/)
cd site && quarto render

The first render pulls ~2.3 GB of StatCan data on first run (components of population change is a large file); subsequent renders read from data/raw/ in seconds. Processed data (data/processed/panel_cma.csv, train.csv, test.csv) and every figure/table are regenerated deterministically.
