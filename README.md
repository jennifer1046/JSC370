## Overview

CMA-level net internal migration in Canada, 2001–2024. Two goals:

- **Primary (prediction).** How much variance in CMA net migration rate per 1,000 population is explained by push–pull structural predictors, and which model family generalises best out of time?
- **Secondary (inference).** Is the 2020–2024 COVID period associated with a structural shift in migration trend beyond what push–pull conditions predict, and does the shift differ by CMA size?

## Reproduce

Requires Python 3.11 with `pandas`, `numpy`, `scikit-learn`, `xgboost`, `statsmodels`, `pygam`, `plotnine`, `plotly`, `requests`, and [Quarto](https://quarto.org/docs/get-started/).

```bash
git clone https://github.com/jennifer1046/JSC370.git
cd JSC370/JSC370_2026/project/canada_migration

# 1. Rebuild the processed panel and every output figure/table.
#    First run pulls ~2.3 GB from StatCan; subsequent runs use the cache.
quarto render migration_analysis.qmd

# 2. Rebuild the written report (HTML).
quarto render final.qmd

# 3. Build the website (outputs to site/_site/).
cd site
cp ../final.html .       # bring the rendered report into the site bundle
quarto render
cd ..

# 4. (Optional) Deploy to GitHub Pages.
cd site && quarto publish gh-pages
```
